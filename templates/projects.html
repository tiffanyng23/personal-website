Spotify Artist Discovery Page

Python (Plotly Dash Framework, Pandas), HTML, CSS

A Spotify Artist Discovery Page that integrates artist data from Spotify's Web API. My goal with this project was to build a page that allows users to explore the music of a new artist in a way that focuses on albums and album tracks. It is meant to be used as an additional tool to the original Spotify Application, specifically to discover the music of a new artist of interest. From this project, I was able to integrate my album-based listening approach with displaying tracks dynamically based on Spotify popularity value (scored from 0-100, based on number of streams and recency of streams).

Earthquake Tracker

Python (Plotly Dash Framework, Pandas), HTML, CSS

A global earthquake tracker dashboard that provides real-time updates on earthquakes using the USGS Earthquake API. The dashboard features a live earthquake counter and a side panel that can be used to customize time window, magnitude, and depth for 3 data visualization tools (scatter plot, scatter map, and data table). The goal of this project was to create a resource that depicts live earthquake data in an accessible and insightful way, and allows for user-driven insights to be gathered on global earthquake events.

NASA Image Repository

Python (Flask Framework, Pandas), HTML, CSS

A webpage that features NASA-released images of Earth taken from space, NASA's astronomy picture of the day (APOD), and a map displaying real-time occurences of various natural events (specifically volcanic eruptions, wildfires, and severe storms). This aim of this project was to create a page for users to easily explore released NASA information and images.
