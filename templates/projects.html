Earthquake Tracker

Plotly Dash

A global earthquake tracker dashboard that integrates the USGS Earthquake API to provide near real-time updates on earthquake events. The dashboard features an earthquake counter and a side panel that allows for customization of time window, magnitude, and depth for 3 data visualization tools (scatter plot, scatter map, and data table). The goal of this project was to create a resource that depicts up-to-date earthquake data in an accessible and insightful way.
